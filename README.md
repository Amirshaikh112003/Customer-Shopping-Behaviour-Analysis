# 🛍️ Customer Shopping Behavior Analysis

An end-to-end Data Analytics project that analyzes customer shopping behavior using **Python**, **PostgreSQL**, and **Power BI** to uncover purchasing trends, customer segments, product performance, and business insights.

---

## 📌 Project Overview

Businesses collect large amounts of customer transaction data, but raw data alone does not provide actionable insights.

This project performs complete data analysis by:

- Cleaning and preprocessing customer transaction data using Python
- Loading cleaned data into PostgreSQL
- Solving business problems using SQL
- Building an interactive Power BI dashboard
- Providing business recommendations based on analytical findings

---

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify high-value customer segments
- Understand spending patterns
- Evaluate subscription behavior
- Compare product performance
- Analyze discount effectiveness
- Create an interactive dashboard for business users

# 🔹 Data Preprocessing (Python)

Performed the following tasks:

- Imported dataset using Pandas
- Explored data using `.info()` and `.describe()`
- Handled missing values
- Imputed missing review ratings using category-wise median
- Renamed columns using snake_case
- Created Age Groups
- Created Purchase Frequency feature
- Removed redundant columns
- Loaded cleaned data into PostgreSQL

# 📌 Key Insights

- Male customers generated higher overall revenue.
- Express shipping customers spent slightly more on average.
- Loyal customers represented the largest customer segment.
- Certain products showed high dependency on discounts.
- Young adults contributed the highest revenue among all age groups.
- Subscription customers had similar average spending but represented a smaller share of total customers.
